# LUMINA

LUMINA is a Diwali-themed ECE competition experience with team registration, four challenge rounds, role-specific Round 1 screens, and a team leaderboard.

## Project instructions

Agents should read [AGENTS.md](AGENTS.md) before changing code. It points to the full product and implementation context in [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md), the agent workflow in [docs/AGENT_WORKFLOW.md](docs/AGENT_WORKFLOW.md), and the reusable partner-agent prompt in [prompts/PARTNER_AGENT_PROMPT.md](prompts/PARTNER_AGENT_PROMPT.md).

## Current prototype scope

- Team registration and sign-in screens
- Round 1: Pataki Clash, with separate Bomb Maker, Thrower, and Builder stations
- Round 2: Crack the Circuit Code
- Round 3: Rangoli Breadboard LED pattern challenge
- Round 4: The Final Boss circuit-building simulator
- Team home and leaderboard pages

The current front-end prototype stores demo state in the browser. It does not provide shared multiplayer state, trusted role assignment, secure scoring, or a production backend.
